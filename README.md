# SDLTA Scorecard

A lightweight, mobile-first scorecard for SDLTA matches.

## What it does

- Records league, division, home team, away team, and two or three rubbers.
- Captures up to three set scores per rubber and totals rubbers and sets automatically.
- Saves the current scorecard only in the browser on the device being used.
- Copies a plain-text match summary for sharing.

## Publish it with GitHub Pages

This repository includes a GitHub Actions deployment workflow. In the repository's **Settings → Pages**, select **GitHub Actions** as the build and deployment source. After merging to `main`, the site will publish at:

`https://azonuzi.github.io/scorecard/`

The workflow follows GitHub's recommended Pages deployment actions.
